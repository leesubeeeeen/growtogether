# ✨ GrowTogether  
**Flutter + Firebase 기반 공동육아 감정 케어 앱**

---

## 📱 소개  
**GrowTogether**는 공동육아 과정에서의 **감정적 불균형**과 **역할 갈등**을 완화하고, 배우자와의 협업을 자연스럽게 이끌어내는 감정 기반 케어 앱입니다.

---

## 🧩 핵심 기능  
- **AI 감정 상담**: GPT 기반 감정 분석 및 맞춤형 조언 제공  
- **육아 일정 공유 캘린더**: 일정 입력 및 시간 선호도 설정  
- **To-do & 알림**: 함께 해야 할 일 관리 및 알림  
- **감정 리포트**: 감정 변화 기록 및 시각화  
- **배우자 연동 기능**: 상대방과 연결하여 데이터 공유

---

## 🛠 기술 스택  
- **Frontend**: Flutter  
- **Backend / Auth**: Firebase Auth
- **AI**: OpenAI GPT API  
- **State Management**: Provider
